# パフォーマンス分析（Performance Analysis）

対象の Azure サブスクリプション / リソースグループを **パフォーマンス効率** の観点で分析してください。
未指定の場合は分析対象（`<SUBSCRIPTION_ID>` / `<RESOURCE_GROUP>`）を最初に確認します。

## 収集する情報（読み取り専用）

- Azure MCP ツールを優先し、利用不可なら Azure CLI (`az`) を代替提示する。
- 主なチェック対象:
  - CPU / メモリ / ディスク / ネットワークの使用率メトリクス（過小・過大）
  - サイズ / SKU 適正化（Right-sizing）の余地
  - ディスク種別（Standard/Premium）と IOPS 要件の整合
  - スケール構成（オートスケール未設定、上限到達）
  - ボトルネック兆候（スロットリング、待ち時間の増大）

| 優先度 | リソース種別 | 指摘 | 推奨アクション |
| --- | --- | --- | --- |

最後に、パフォーマンス上の要注意点と、優先的に対処すべき項目をまとめてください。

## 注意

- 破壊的操作やスケール変更は行わず、推奨アクションの提示に留める。
- メトリクスは期間・負荷により変動するため目安として扱う。
- 実 ID・リソース名を含めず、プレースホルダを使用する。
