影響度の判定ルール

影響度 = 重大度 S（何が起きるか）× 緊急度 U（いつ起きるか）。S は本文の明記に基づくフラグから決定論的に算出し、明記が無いフラグは「不明」として保守的に扱う。

区分条件
S3（重大）リタイア後にワークロードが停止・利用不可になる、またはデータ / リソースが削除・消失すると本文に明記
S2（中）上記・下記のいずれにも当たらない（停止・消失が「不明」を含む。利用者側の移行作業が必要）
S1（軽微）Microsoft による自動移行 / 自動アップグレードが本文に明記され、停止・消失の明記が無い
U3（至急）リタイア済み、当月（日付未確定）、または残り 90 日以内
U2（計画）残り 365 日以内
U1（中長期）残り 365 日超
要確認リタイア日が特定できない、または本文から影響を判定する根拠が不足
