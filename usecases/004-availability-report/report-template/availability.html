稼働率は Resource Health の availabilityStatuses・Azure Monitor の可用性メトリック・アクティビティログから対象期間を集計した目安。SLA 目標は、非機能要求グレードで定義した「構築中システム自身の SLA / 稼働率目標」（入力ファイル sla-targets.csv）であり、Azure サービスの公表 SLA ではない。目標が未入力のリソースは「未入力（要指定）」とし、達成判定は行わない。

稼働率の算出方法

本レポートの稼働率は、対象期間の停止時間を差し引く時間ベースの概算（目安）です。厳密な SLA クレジット計算ではありません。

  • 算出式: 稼働率(%) =（期間の総分 − ダウンタイム分）÷ 期間の総分 × 100
  • ダウンタイムの求め方: Resource Health（availabilityStatuses／アクティビティログ）で Unavailable・Degraded だった時間、または Azure Monitor の可用性メトリックが閾値を割った時間を合算する。リソース種別により算出方法が異なり、各行の「ダウンタイム / 算出方法」列に情報源と方法を記載する。
  • 総合可用性（概要ページのゲージ）: リソース別稼働率の平均。
  • 目標との突合: 稼働率 ≥ SLA 目標（sla-targets.csv の入力値）なら「達成」。目標が未入力のリソースは判定しない（Azure 公表 SLA では代替しない）。RTO/RPO は目標値の表示のみで実測はしない。
  • 限界: 情報源の粒度・保持期間に依存する概算。可用性メトリックを持たない種別など算出できない場合は「確認不可」と明示する。
